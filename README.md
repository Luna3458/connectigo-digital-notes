# AI 开始在手机上识别骗局，我们也该重新整理自己的上网习惯

> 2026 年 10 月 14 日 · 网络生活观察

今天，Google DeepMind 发布了一项与新加坡政府科技局 GovTech 合作的成果：基于 Gemma 的端侧诈骗检测模型。

据官方介绍，该模型在设备本地分析对话，识别可能存在的操纵行为，并向用户发出提醒，减少将私人对话上传到云端处理的需要。

这条消息值得关注的地方，是一个很具体的问题：**我们能否在获得帮助的同时，少交出一些个人信息？**

## 链接越来越多，判断不能越来越少

每天打开浏览器，我们会遇到产品推荐、工具教程、注册邀请和限时活动。

页面做得漂亮，不代表信息可靠；一段介绍写得像真实体验，也不代表作者做过测试。

尤其是涉及账号登录、购买订阅或下载客户端时，值得多看一眼：

- 域名是否与自己保存的地址一致？
- 页面是否清楚说明价格、有效期和使用限制？
- 下载入口是否来自软件开发者或可信渠道？
- 所谓“客服”是否索要密码、验证码或完整订阅链接？

工具可以帮忙识别风险，自己的判断仍然重要。

## 给常用服务留一个固定入口

一个容易执行的习惯，是把常用服务保存成书签。

需要续费、查看公告或调整配置时，从已经确认的入口进入，减少临时搜索和反复寻找地址的麻烦。入口发生变化时，再通过已知渠道核对。

对于节点订阅，访问网站的地址与个人订阅链接也要分开保存：前者用于进入服务页面，后者可能包含账号访问凭证，不适合公开分享。
